Upload Student CSV

Before you upload:

  • The header row must match exactly — download the template below rather than typing headers by hand.
  • Required: first_name, last_name, date_of_birth, gender, cnic, contact_no, marital_status, religion, nationality, guardian_name, guardian_cnic, relation_with_guardian, emergency_contact_no, present_address, province, district, city.
  • Optional: guardian_contact_no, program, roll_number, admission_fee_paid, enrollment_date.
  • CNIC format: 12345-1234567-1. Phone format: 03XXXXXXXXX or +923XXXXXXXXX. Dates: YYYY-MM-DD.
  • Use the .xlsx template if you're editing in Excel — its phone/CNIC columns are pre-formatted as Text so Excel can't corrupt them, even across hundreds of rows you add yourself. The plain .csv template only protects its one example row.
  • If any row fails validation, the entire file is rejected — nothing is imported until every row is fixed. Check Import History below for the exact row/field errors.
  • New student accounts are created automatically with a default password, forced to change on first login.
